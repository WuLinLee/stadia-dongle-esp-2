ESP32-S3 固件在线刷入

将 Google Stadia 蓝牙手柄转换为 Windows 可识别的 Xbox 360 / XInput USB 手柄。此页面由本项目仓库维护，刷入用的固件和配置页也来自本项目。

  1. 1使用支持数据传输的 USB 线，将 ESP32-S3 接到电脑的 COM / UART 烧录接口。不要选择开发板日常使用的原生 USB / OTG 接口。
  2. 2点击下方 Install，在浏览器弹出的设备列表中选择正确的串口，然后等待刷入完成。
  3. 3刷入后拔掉 USB，改接开发板的 原生 USB / OTG 接口。Windows 中运行 joy.cpl，确认 Xbox 360 兼容手柄已出现。
当前浏览器不支持 Web Serial。请在桌面版 Google Chrome 或 Microsoft Edge 中打开此页面。
下载完整刷写固件 (.bin) 打开 USB 配置页 最新版本 / Releases

注意：这是完整刷写镜像，不是 OTA 应用镜像。完整刷写可能影响已保存的配对信息；若升级后手柄不能自动重连，请在 USB 配置页重新配对。刷入过程由浏览器直接与开发板通信；页面通过 ESP Web Tools 加载串口刷写组件。
